# 🎨 Color Gradient Generator

This **Color Gradient Generator** is a simple and interactive web tool that allows users to create and customize gradient backgrounds with ease. Users can select gradient types, adjust colors, modify directions, and copy the generated CSS code.

## 🚀 Features

- **Supports Linear & Radial Gradients**: Choose between linear and radial gradients.
- **Customizable Directions**: Select gradient directions (top, bottom, left, right, etc.).
- **Color Selection**: Pick colors using the built-in color picker.
- **Random Gradient Generation**: Instantly generate random color combinations.
- **Live Preview**: See real-time updates as you modify gradient settings.
- **Copy CSS Code**: Easily copy the generated CSS code for use in projects.

## 🛠️ Technologies Used

- **HTML**: Structure of the tool.
- **CSS**: Styling and layout.
- **JavaScript**: Handles gradient generation, user interactions, and copy functionality.


## 🏗️ How to Use

1. Choose a **Gradient Type** (Linear or Radial).
2. If using a **Linear Gradient**, select a **Direction**.
3. Pick **Colors** using the color picker.
4. For **Radial Gradients**, adjust the **percentage stops** for color blending.
5. Click **Refresh Color** to generate random gradients.
6. Click **Copy Code** to copy the CSS code for your gradient.

## 💻 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ruzdaansari/color_converter.git
   ```
2. Open `index.html` in a browser to use the tool.
